# Submission screenshot checklist

Capture these views from the deployed URL after seeding jobs and creating one demo account:

1. Public jobs homepage with search, filters and job cards.
2. Job details with the login-free Apply action.
3. Candidate dashboard with recommendations and search-status controls.
4. Profile with preferences, professional links and resume upload.
5. Employer job posting and My Jobs management.
6. Applications workspace with status, notes, resume download and CSV export.
7. Admin dashboard with statistics, job moderation and user deletion.
8. Mobile-width public jobs view.

Do not include real passwords, database connection strings, private resumes or personal candidate information in the captures.
